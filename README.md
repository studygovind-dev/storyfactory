# Story Factory - Windows, 3 steps

1. Unzip this folder. Install ffmpeg is automatic (no need for the .tar file).
2. Double-click  SETUP_FIRST.bat   (installs tools, asks for your keys)
3. Double-click  TEST_FREE.bat     (free test video)
4. Double-click  MAKE_EPISODE.bat  (real video, arrives on Telegram)

Optional for better quality:
- Save one face picture per character in assets\characters\ (daniel.png, mia.png ...)
- Save a royalty-free sad music file as assets\music.mp3

Rules: write your own stories only. Turn ON the AI-content label when posting.
